# Finished Product Target

## Core proposition

Upload whatever the supplier sends. StockShift tells the customer:

- what changed
- which products are new or removed
- which records are likely renamed/replaced
- where pack/UOM changed
- which price movements damage margin
- which records need human review
- what approved data should be exported

## Inputs

- CSV
- XLSX
- digital PDF
- scanned/image PDF
- mixed supplier layouts

## Outputs

- exact price increases/decreases
- new/removed products
- SKU/manufacturer part-number changes
- pack/UOM changes
- likely replacements/renames
- gross-margin impact
- configurable margin-threshold warnings
- review queue
- CSV/XLSX exports
- saved customer-specific import mappings

## Competitive position

StockShift is not just a spreadsheet comparer.

The product should complete the workflow:

**supplier document → trusted structured data → reconciled catalogue → commercial impact → reviewed import-ready output.**

## Non-goals

- full ERP
- warehouse management
- purchasing system
- POS
- CRM
- general accounting
- automatic downstream write-back before export workflows are proven
